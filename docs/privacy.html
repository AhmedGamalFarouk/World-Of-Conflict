World Of Conflict: privacy policy

World Of Conflict is an offline Android game. It is fully playable without a connection. There are no accounts and no advertising. By default it makes no network requests and collects no data. The only exception is anonymous usage stats, which are off unless you choose to share them.

Optional usage stats

On first launch (in builds that have this enabled) the app asks Help improve the game? The default, and what Android back does, is No thanks. You can switch it any time in About (Usage stats: on/off); turning it off deletes unsent queued events. Builds without a key send nothing and show no prompt.

If you share, the app sends these to Aptabase, an analytics service:

  • the event name and a timestamp,
  • a random session ID made for one app launch (it is not a device ID, and is kept on the device only inside events waiting to be sent),
  • your device language setting, the app version, and whether it is a development build,
  • event details: the map, difficulty and whether it was the daily challenge when a game starts; how it ended (win, loss, quit or abandoned) and its length in minutes; the daily challenge result; and the code of an error, such as save.damaged (never the message or stack), at most once per code per launch.

It does not send an account, player name, device ID, advertising ID, location, error messages, stack traces or game contents. Aptabase's servers see your IP address and user agent with each request; per Aptabase's privacy policy they process them only in memory and never store them. Aptabase keeps the events for up to 5 years and cannot tell which events came from you, so they cannot be deleted per person; turning the stats off stops all further events. Events made while offline are kept on the device (at most 100) and sent later.

What stays on your phone

The app keeps these on the device only, and uninstalling removes them:

  • your settings (for example vibration and graphics options),
  • a count of games started and finished, and their lengths,
  • one saved game, so you can continue it later,
  • a short error log. It is only shared if you choose Copy error log in About and paste it into a bug report yourself.

Permissions

The app declares the INTERNET permission because the Android web view requires it and for the optional usage stats above; without opt-in it makes no requests. It also uses VIBRATE for haptic feedback, which you can switch off in settings.
